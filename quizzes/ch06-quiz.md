## Multiple Choice (10 questions)

**1.** Which of the following best distinguishes an AI *agent* from an AI *tool*?

a) Agents are more expensive to use than tools  
b) Agents can take autonomous actions and use external tools to achieve a goal  
c) Tools can write longer text than agents  
d) Agents require programming knowledge; tools do not  

**2.** According to Malcolm Knowles' theory of andragogy, adult learners are best characterized as:

a) Passive recipients of information delivered by experts  
b) Learners who need structured curricula to guide them through content  
c) Self-directing, experience-driven, problem-centered, and motivated by immediate relevance  
d) Motivated primarily by grades and external evaluation  

**3.** In the anatomy of a useful agent, "guardrails" refer to:

a) The software infrastructure that keeps the agent running  
b) Rules that explicitly limit what the agent can do autonomously  
c) The memory the agent maintains across sessions  
d) The tools the agent has access to  

**4.** According to Self-Determination Theory (Deci & Ryan), which three basic psychological needs must be fulfilled for humans to flourish?

a) Achievement, Recognition, and Security  
b) Autonomy, Competence, and Relatedness  
c) Mastery, Purpose, and Autonomy  
d) Belonging, Esteem, and Self-Actualization  

**5.** Under FERPA, what is the correct approach when using a personal Google account with AI agents?

a) You may share all student data freely, since Google has FERPA compliance  
b) You should avoid entering student personally identifiable information into personal account AI tools  
c) FERPA only applies to official school records, not AI tools  
d) You must get parental consent each time you use AI for grading  

**6.** Which of the following is an example of an appropriate guardrail for a Parent-Update Writer agent?

a) "Draft and send all parent emails automatically at 8 a.m. on Mondays"  
b) "Never draft emails — always ask the teacher to type them manually"  
c) "Draft all emails as Gmail drafts for teacher review before sending"  
d) "Send emails only to parents who have opted into AI communication"  

**7.** The "Substitute Folder Agent" described in Chapter 6 demonstrates which core capability of AI agents?

a) The ability to replace a teacher's professional judgment with data-driven decisions  
b) The ability to execute a multi-step, context-aware task from a single input prompt  
c) The ability to interact directly with students during the school day  
d) The ability to automatically grade student work without teacher input  

**8.** A teacher who feels that their district *mandates* AI tool use without giving them a choice is most likely experiencing a threat to which SDT need?

a) Competence  
b) Relatedness  
c) Autonomy  
d) Achievement  

**9.** When setting up a Grading Assistant agent, the teacher provides their rubric, feedback standards, and preferred tone in the goal statement. This practice most directly reflects which Andragogy principle?

a) Adults need external motivation to engage with new technology  
b) Adult learners bring experience that should shape how new tools work for them  
c) Adults prefer technology that makes decisions independently  
d) Adult learning must be supervised by a credentialed instructor  

**10.** Which statement best describes the "review step" in the Assign → Execute → Review cycle for agent supervision?

a) It is an optional step for experienced users who trust their agents  
b) It is where the teacher's professional judgment is applied before output is used  
c) It is primarily a compliance activity for administrators  
d) It is only necessary when the agent has made a visible error

## Short Answer (3 questions)

**11.** Explain the difference between an AI *tool* and an AI *agent*, using a specific example relevant to K–12 teaching. Your answer should address at least two distinguishing characteristics (goal orientation, autonomy, or tool use).

**12.** Using Self-Determination Theory, explain how the same AI agent could either *fuel* or *drain* a teacher's professional motivation depending on how it is adopted. Give one example of each scenario.

**13.** A teacher wants to build an IEP/504 Drafter agent. Write a 3–5 sentence goal statement for this agent that includes: (a) what the agent should produce, (b) what information it has access to, (c) at least one explicit guardrail.

## Answer Key

**Multiple Choice:**

1. **b** — Agents can take autonomous actions and use external tools to achieve a goal. (Section 6.1)
2. **c** — Self-directing, experience-driven, problem-centered, and motivated by immediate relevance. (Section 6.3, Knowles 1968/1970)
3. **b** — Rules that explicitly limit what the agent can do autonomously. (Section 6.5)
4. **b** — Autonomy, Competence, and Relatedness. (Section 6.10, Deci & Ryan 1985/2000)
5. **b** — You should avoid entering student personally identifiable information into personal account AI tools. (Section 6.11, FERPA)
6. **c** — Draft all emails as Gmail drafts for teacher review before sending. (Section 6.8)
7. **b** — The ability to execute a multi-step, context-aware task from a single input prompt. (Section 6.7, Sub-Plan Generator)
8. **c** — Autonomy — the need to feel that one's actions originate from one's own values and choices. (Section 6.10)
9. **b** — Adult learners bring experience that should shape how new tools work for them. (Section 6.3, Experience-Driven principle)
10. **b** — It is where the teacher's professional judgment is applied before output is used. (Section 6.9)

**Short Answer Rubric:**

*Question 11:* Strong responses will contrast a chatbot (responds when prompted, generates text, no action in the world) with an agent (pursues a goal, accesses external tools like Drive or Gmail, acts across multiple steps without continuous prompting). Example quality matters — teacher-specific examples score higher.

*Question 12:* Fueling scenario should show autonomous adoption, expanded capability, or increased time for student relationships (all SDT-positive). Draining scenario should show mandated adoption, loss of skill, or reduced human connection (all SDT-negative). Strong responses will name the specific need being affected.

*Question 13:* Scored on specificity of output description (3 pts), clarity of information access (1 pt), and quality of guardrail — "DRAFT only" and human review requirement are the expected guardrail elements (1 pt). Deduct for goal statements that are too vague to function as real agent instructions.
